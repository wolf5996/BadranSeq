# Internal Split.by Silhouette Implementation

Creates split panels where each panel shows cells of that category in
color with a grey silhouette of all other cells in the background.

## Usage

``` r
.do_DimPlot_split_silhouette(
  plot_data,
  colors.use,
  group_var,
  label,
  label.size,
  label.color,
  label.fill,
  label.box,
  pt.size,
  pt.alpha,
  plot.axes,
  raster,
  raster.dpi,
  na.value,
  plot_cell_borders,
  border.size,
  border.color,
  ncol
)
```
